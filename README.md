# Maze — генерация и решение лабиринтов и пещер

Учебный проект (21 School, A1_Maze на Kotlin). Настольное приложение на Compose
Desktop со встроенным веб-сервером Ktor: и окошко, и браузер работают с одним и
тем же ядром на Kotlin — в JavaScript нет ни одного алгоритма.

## Возможности

- Генерация идеального лабиринта алгоритмом Эллера.
- Генерация пещер клеточным автоматом.
- Поиск кратчайшего пути обходом в ширину.
- Агент на Q-learning, который сам учится проходить лабиринт.
- Загрузка и сохранение лабиринтов и пещер в текстовом формате ТЗ.
- Веб-интерфейс (Vue, лежит локально — интернет не нужен).

## Запуск

Нужен JDK 21. Gradle Wrapper уже в репозитории.

```bash
make run          # или ./gradlew run
```

Приложение откроет окно и браузер на <http://localhost:9090>. Порт можно задать
переменной `PORT`; если он занят, берётся следующий свободный.

Другие команды `make`:

| Команда | Что делает |
|---|---|
| `make build` | сборка и тесты |
| `make tests` | только тесты |
| `make install` | установка в `app/build/install/maze` (или `INSTALL_DIR=...`) |
| `make dvi` | HTML-документация из KDoc |
| `make ktlint` | проверка стиля Kotlin |
| `make clean` | удалить артефакты сборки |

## Web API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/` | веб-интерфейс |
| `GET` | `/api/maze?rows=&cols=` | сгенерировать лабиринт |
| `POST` | `/api/maze` | лабиринт из тела запроса (текстовый формат ТЗ) |
| `POST` | `/api/solve?...` | решить присланный лабиринт |

```

  web/                Ktor-сервер и веб-страница

```
